# Tessera Launcher

Launcher de Minecraft: Java Edition para Windows, com instâncias, mod loaders (Fabric, Quilt, Forge,
NeoForge) e a biblioteca do Modrinth.

> Não oficial. Não aprovado pela Mojang ou Microsoft.

## Baixar

Pelo site: **https://tessera.discloud.app**

Ou direto na [última versão](https://github.com/JamalOruim/tessera-launcher/releases/latest):

- **`Tessera-Launcher-Setup-<versão>.exe`**: instalador. **Recomendado**, porque se atualiza sozinho.
- **`Tessera-Launcher-<versão>-portatil.exe`**: roda sem instalar. Avisa quando há versão nova, mas a
  atualização é manual.

O `.exe` ainda não tem assinatura digital, então o Windows pode mostrar "O Windows protegeu o
computador". Clique em **Mais informações → Executar assim mesmo**.

## Atualizações

O launcher instalado procura versões novas aqui, nos Releases deste repositório, ao abrir e a cada
6 horas. O arquivo baixado só é aceito se o hash (sha512) bater com o publicado no `latest.yml`.
Dá para desligar em **Configurações › Atualização automática**.

Este repositório guarda só os lançamentos.
